data/ contains the compact numerical inputs; source_diagnostics/ contains the
original evaluation plots for the three selected CFG settings. No model was
sampled and no physics metric was recomputed by this CPU-only job. See
figure_manifest.json for immutable PVC provenance and PLOT_CATALOG.md for the
